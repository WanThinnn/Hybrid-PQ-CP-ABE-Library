# CoverCrypt Plugin

Optional CoverCrypt integration layer for Hybrid-CP-ABE-Library.

- Integration/bridge code owned by this project belongs here.
- Upstream Cosmian CoverCrypt source is vendored separately under `vendor/cover_crypt/`.
- Upstream attribution and BUSL-1.1 license are retained in `vendor/cover_crypt/UPSTREAM.md` and `vendor/cover_crypt/LICENSE.md`.
- The core `src/` tree remains C++ only.

The CoverCrypt bridge is not enabled in the stable v5.2.0 core yet.
