# Hybrid PQ-CP-ABE Library — Version 6.0.1

## Overview

Version 6.0.1 adds a **WebAssembly SDK** built on Linux for browser and Node.js
applications. It exposes the public C API through an Emscripten module and
supports AC17, TKN20, and CoverCrypt, including CoverCrypt with ML-KEM-768,
AES-GCM encryption, and optional ML-DSA-87 signing and verification.

## New Feature: WebAssembly SDK

- File and buffer APIs support setup, key generation, encryption, and
  decryption for all three ABE schemes. File APIs use an in-memory filesystem.
- Import `lib/wasm/loader.mjs` to initialize the library and the Go runtime for
  TKN20. Keep the five JavaScript and WebAssembly runtime files together.
- The SDK includes public headers and `libhybrid-pq-cp-abe.a` for Emscripten C
  and C++ applications. The CLI entry point is available through `callMain`.

## Build System & Release Artifacts

Build and test from source on Linux with Emscripten 7.0+, Rust nightly with
`rust-src`, and Go. See the [WASM build guide](../bindings/wasm/README.md) for
toolchain setup and integration examples.

```sh
make wasm -j8
make wasm-test -j8
```

- The release includes `libhybrid-pq-cp-abe_wasm_v6.0.1.zip` alongside the four
  native SDK archives and the Linux Vault plugin archive.
- The WASM ZIP contains the runtime files, static archive, public headers,
  documentation, and dependency notices. Its checksum is listed in
  `SHA256SUMS.txt`.
- Release CI runs the Node.js smoke suite against the extracted ZIP. It covers
  all three schemes, file and buffer round trips, policy denial, ML-DSA-87
  signing and verification, and rejection of modified ciphertext.

## Usage

Extract the ZIP and import the loader from the package directory:

```js
import createHybridCPABE from './lib/wasm/loader.mjs';

const abe = await createHybridCPABE();
console.log(abe.ccall('getVersion', 'string', [], []));
```

In a browser, serve the runtime files over HTTP(S) from a secure context such
as HTTPS or localhost. Use `abe.FS.writeFile` and `abe.FS.readFile` to transfer
data through the file API.
